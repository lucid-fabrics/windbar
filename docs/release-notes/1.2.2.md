The TurboCool Misting Fan 765S now shows its mist. Its card gains a Misting switch, a Mist
Level picker from 1 to 4, an Oscillation switch and the Natural mode, none of which Dreo's own
config describes for this model. Picking a mist level while misting is off turns misting on
first, so the control never looks like it did nothing. The values come from the owner's device
report and from how the Home Assistant integration drives this fan, not from our own
hardware, so they are waiting on confirmation from someone standing next to one.

Every card now says what its fan is doing, open or closed: speed, misting, temperature and
humidity where the fan reports it, and a red "Tank empty" warning when a misting fan runs dry.
A drop on the fan icon shows at a glance which fans are misting. The model code that used to
sit there lives in the device report instead.

The unlabelled "…" button is gone. Copy Trigger Link, Copy Device Report and Remove Device
are named rows under More options, which is now an actual button, and an offline fan can
still be reported or removed. An account with no fans gets an Add a Device button right in
the middle of the popover, and the pairing screen's 2.4 GHz reminder is now readable instead
of a faint footnote.
