**Presets.** Get a fan how you like it, save that as "Desk" or "Night", and give it a keyboard
shortcut. One press sets the fan up and turns it on. Press it again while the fan is already in
that shape and it turns off, so a single key covers both directions.

Every fan now has its own Shortcuts list holding a Power key plus a key per preset, which
replaces the single global hotkey that used to toggle whichever fan you touched last.

Fans fold down to one line each, so several of them no longer fill the screen. The TurboPoly
508S gets its Turbo mode and its ambient light, colour and display controls, worked out against
real hardware. Commands are also sent one at a time per fan now, which fixes the "wouldn't
accept that setting" errors that showed up when a slider was dragged quickly.

**This is the last update you install by hand.** From here, Windbar checks for new versions
itself and there is a Check for Updates item in the menu.

**You will have to sign in to Dreo once after installing this.** Getting an updater working
means this build can no longer run inside the App Sandbox, and macOS ties a saved password to
the app that saved it, so the old one is not offered to the new build. Your presets, shortcuts
and settings all carry over. Only the password has to be typed again, once.
